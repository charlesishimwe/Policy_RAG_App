
# AI Tooling Disclosure

## Tools used
- ChatGPT: assistance with implementation planning, code drafting,
  debugging guidance, and documentation.
- OpenRouter: LLM API gateway used by the application.
- Sentence Transformers: local text embedding model.
- ChromaDB: vector storage and similarity retrieval.

## Human verification
Code and generated documentation must be reviewed and tested.
Evaluation metrics must come from actual runs. API credentials
must remain private. Synthetic policies are used for demonstration.

## Reproducibility
Document the Python version, dependency versions, model identifiers,
environment variables, ingestion command, and test commands.
